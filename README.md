# IBGDH Platform Launch

Olá, Lovable! 
Tudo bem?
"Crie a estrutura base de uma plataforma web institucional para o IBGDH (Instituto Brasil Global de Direitos Humanos).

Diretrizes de Design & Tom:

Estilo moderno, limpo, acessível, focado em impacto social, transparência e autoridade.

Paleta de cores: Azul institucional como cor primária, tons neutros de cinza/branco para fundo e contrastes e destaques suaves para CTAs (botões de ação).

Tipografia legível e acessível.

Cabeçalho/Navegação (Header): Crie um menu superior responsivo (com menu hambúrguer no mobile) contendo as seguintes abas e dropdowns:

Início

Instituto (Subitens: Quem Somos; Missão, Visão e Valores; Diretoria; Patrono; Parceiros)

Direitos e Serviços (Subitens: Pessoas com Deficiência; Assessoria Jurídica; Projetos Sociais)

Conhecimento (Subitens: Artigos; Pesquisas; Publicações)

Escola IBGDH (Subitens: Cursos; Eventos)

Contato Inclua no lado direito do menu um botão de destaque (CTA): 'Solicite Orientação'.

Rodapé (Footer): Rodapé completo com links rápidos da navegação, redes sociais, endereço/contato e área de direitos autorais."
